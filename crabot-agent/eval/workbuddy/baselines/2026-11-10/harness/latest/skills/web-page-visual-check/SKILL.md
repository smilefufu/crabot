---
name: web-page-visual-check
description: 依据用户提供的视觉和响应式要求，通过实际渲染检查所编写的浏览器页面。
---

以当前用户要求和提供的参考材料为准。本流程不授予额外功能的开发权限，也不替代对来源事实的判断。

1. 做视觉决策前，先用可用的读图工具查看参考图片。根据实际运行环境选择可用的浏览器操作方式；某个可执行文件不存在，不等于没有可用的浏览器库。
2. 按用户要求的视口和状态渲染最终页面，检查加载错误、应有内容、页面溢出和必要交互。临时截图保存在已授权的工作区内。
3. 用 Read 打开清晰可读的视口或分区截图，检查文字和图表标签是否易读，以及裁切、重叠和固定控件问题。几何检测通过或截图写入成功，不能证明页面在视觉上可用。图表或文字依据所给数据生成时，核对重要结论与实际来源是否一致，明确单位和不确定性。
4. 在任务范围内修复已观察到的问题，重做受影响的检查。报告实际结果和限制，不能仅凭查看页面代码就声称渲染验收通过。不再需要时清理临时文件，保留用户要求的证据。
