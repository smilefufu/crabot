# 模板演示文稿交付

1. 阅读来源材料的层次、相关备注及附件，以及参考截图。用 Read 打开参考图片；提取文字或测量图片尺寸，不能代替理解图片内容。
2. 按用户指定的受众和来源意图，将保留的材料分配到受众可见页面、演讲者备注，或明确标注适用条件的材料。普通幻灯片即使标为“后台”，正常放映时仍会显示。将编辑指令落实到演示文稿中，不把指令本身当作受众内容展示。不能为填补缺口而编造事实或承诺。
3. 生成整份演示文稿前，用最小副本验证实际需要的模板操作：复用或新增页面；需要备注时，验证写入并重新打开备注。接口不可用时，检查实际库和模板结构；不能悄悄丢弃内容，也不能为绕过写入失败而把仅供演讲者的指令放到受众页面。
4. 保存并重新打开实际 PPTX，对照选定材料检查页序、内容可编辑性、备注文字及模板残留。有可用的演示文稿渲染器时，渲染最终页面，并用 Read 打开有代表性的输出图片，检查可读性、裁切和布局。区分库或 XML 检查与实际渲染审阅；无法渲染时说明缺口，不声称视觉验收通过。
5. 修复后重查受影响的页面，保留有效产物，清理临时验证材料。报告实际检查、文件位置和重要限制。
