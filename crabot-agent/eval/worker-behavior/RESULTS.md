## 评测器局限与归因

原模拟器发现健康 Worker 错带旧阻塞、旧停止状态泄漏到新 Worker、替换 ID 重用、send_to_worker 忽略目标，以及复合 shell 已执行前缀丢失回执等问题。Manager 的旧 objective 标记还把普通发送消息当作结果线索。当前评测器已修复这些确定性缺陷并补回归，原批次对应源码快照与哈希保留，没有使用新评测器回填旧记录。

开发、保留、修订开发、定向复查分别有 44、19、24、4 条最终轨迹遇到未建模操作。有限模拟器不支持全部合法 shell 和 Manager 操作；其粗略 Worker 完成回执也不足以支撑独立产物验收。Manager 的追加验证和轮次耗尽混入了这些影响，不能全部归因于提示词，也不能宣称完整纠偏链已通过。

本轮语义阅读时能看到候选标签，没有满足 spec 的盲评要求。最初保留集已使用，不能通过重命名或再次调词恢复独立性。完整行为通过数保持未判定；已证明的失败、观察到的正向行为和未验证范围分开保留。
