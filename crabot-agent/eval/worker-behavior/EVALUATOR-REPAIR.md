明确的主控参数错误有 3 条：压缩后续办漏传事项 title；换新样本传空 blocker；同一样本归档时抄错目标 ID。前两条随后改正，错误 ID 出现在预算最后一轮，未观察到恢复。真实工具校验现在会暴露这些错误，不能改成成功回执来提高“通过率”。

收尾效率也可直接观察：一条自省轨迹在第 7 个决策轮次已汇报结果，之后依次修订任务板、处理回合、停止已闲置的新 Worker、归档事项、归档目标，用完余下 5 轮。这支持收尾繁琐的判断，不证明一个通用的工具调用数阈值。

压缩后续办第 3 次要求全面查文件、独立核验，模拟 Worker 却仍返回固定报告结果，主控两次追加要求后用完预算。此处既有派发范围扩大，也有固定回执不能响应追加要求的局限，不能全部归因于提示词。
